## Contrato

- POST `/api/pedidos/:id/ubicacion/candidatos`: admin/operador autenticado; resultado con version, provider, status y hasta 10 candidates (label, lat/lng nullable, quality). Estados zero_results, multiple_results, approximate y no_coordinates; errores GEOREF_TIMEOUT, GEOREF_LIMIT, GEOREF_UNAVAILABLE e INVALID_RESPONSE. No inventa score ni cambia dirección/estado. Se registran intentos y errores en historial_geolocalizacion, nunca como confirmación.
- POST `/api/pedidos/:id/ubicacion/confirmacion`: version, lat, lng numéricos y observation obligatoria de hasta 1000 caracteres; rechaza otros campos. Transacción bloquea pedido/dirección y exige dirección completa, versión actual y estado previo al despacho. Registra snapshot, versión, coordenadas a ocho decimales, usuario y fecha; reintento idéntico del mismo usuario conserva la revisión existente.
- El detalle devuelve confirmation solo si coincide la revisión actual. Una sugerencia o un booleano histórico no bastan. La UI exige marcar revisión personalmente; editar coordenadas desmarca esa casilla. Corrección por clic o coordenadas permite teclado. Responsabilidad: la API verifica identidad y vigencia; la revisión visual la realiza la persona.

## Fuentes oficiales consultadas

[Normalización de direcciones Georef](https://www.argentina.gob.ar/node/473623): cobertura nacional con efectividad variable, ubicaciones estimadas y valores faltantes. Usamos API v2.0; no asumimos precisión por altura, score, cuota garantizada ni disponibilidad contractual. Servicio público sin clave/facturación en esta integración; almacenamiento de revisión/resultado es local, sin contratación. La documentación consultada no aporta garantía de disponibilidad ni condiciones específicas de retención de respuestas; verificar antes de producción.

[Leaflet 1.9.4](https://leafletjs.com/reference-1.9.4.html): dependencia local para mapa, controles y marcación; sin wrapper React adicional. [Política de teselas OSM](https://operations.osmfoundation.org/policies/tiles/): HTTPS, atribución visible, sin descarga masiva/offline/prefetch, caché normal del navegador y Referer habitual. La demo usa tile.openstreetmap.org; su servicio no garantiza SLA y debe reevaluarse para despliegue/carga mayor.

Consulta real de dirección pública de ejemplo (Av. Santa Fe 260, Córdoba) falló; diagnóstico HTTPS devolvió HTTP 500. Fixtures acreditan el contrato y errores, no cobertura real. OSM sí renderizó en navegador QA.
